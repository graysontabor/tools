    Turn the letters into PDFs

    Using Kofax Power PDF
    1. Click Create letters, then unzip the download (right-click it → Extract All).
    2. Open Kofax Create Assistant: Windows Start → Kofax Power PDF → Create Assistant. (Or in Power PDF: File → New → From File → Create PDFs from multiple files.)
    3. Drag the letter Word files into the list. To select them all, click the first one and Shift-click the last. Leave out _Report.csv and _All letters combined.docx.
    4. In the drop-down under the list, choose Create a PDF for each input document, then click Create.

    Each PDF keeps its letter's file name (e.g. N. W. HOUSTON FAMILY PRACTICE, P. A..pdf). If Kofax asks you to name every file, change its destination setting so it saves to a folder automatically. Want one PDF with every letter for printing? In step 4, choose Combine files into one PDF document instead; Kofax can add a bookmark for each letter.

    Setups

    Your choices (which column goes where, rules, file names) are remembered automatically in this browser for each template file name, so next time you load the same template it will be set up for you.

    To give a coworker the same setup, save a setup file and send it with the template. They click Load a setup file after opening the template.

    How it works

    Letter Builder makes one Word letter for every row in a spreadsheet. It runs entirely inside your web browser: nothing is uploaded and no internet connection is needed. Keep this file anywhere (your desktop, a shared drive) and double-click it to open.

    1. Template

    Use your normal Word letter. Anything in [square brackets] is picked up automatically, for example [Name of Participant]. {{double braces}} and «chevrons» also work. If a spot to fill in isn't in brackets, type it exactly as it appears under “Other text to replace”. Bracketed text that should stay as written can be clicked to switch it off.

    The same placeholder can appear many times, including in headers and footers; every copy is filled in. Formatting (bold, font) is kept.

    2. Spreadsheet

    Any .xlsx or .csv works, with any columns. If there are title rows above the column names (common in exports from Monday.com and similar tools), the tool finds the header row for you. You can correct it if needed.

    3. Fill in

    For each spot, pick a column, type text that's the same on every letter (like the date), or combine columns, such as an address built from several columns, one per line. Write column names in curly braces, e.g. {Address City}, {Address State} {Address Zip Code}. Blank lines (e.g. an empty Address Line 2) are dropped automatically.

    4. Rows

    Add rules to include only certain rows, and untick any individual rows you don't want.

    5. Create

    Preview any letter first. Create letters downloads a .zip with one Word file per letter plus _Report.csv, which lists every letter and any missing information. Need PDFs? See “Turn the letters into PDFs” at the bottom of the main page.

    Good to know

    • Text in the letters appears exactly as it is shown in Excel (dates, currency, leading zeros).
    • Older .xls files: open in Excel and save as .xlsx first.
    • The tool fills in spots but doesn't add or remove paragraphs depending on the row (for example, “include this clause only for New York”). When letters need different wording, keep a separate template for each version and use a rule in step 4 to pick the matching rows.
    • In the combined document, headers and footers show the first letter's values. Individual letters are always correct.
